# Iconografía de infraestructura

- `fly-io.svg`, `vultr.svg` y `cloudflare.svg` reproducen los SVG de Simple Icons que ya están incrustados en los diagramas de Ryguasu y Fil-Grama, con sus colores de presentación.
- `aws.svg` es el isotipo monocromo de AWS procedente de [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/amazonaws.svg).
- `aws/` contiene 29 SVG de servicios y recursos del paquete de [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), seleccionados del conjunto usado para diagramar infraestructura. Los nombres y colores de los archivos se conservan.

Las marcas pertenecen a sus respectivos titulares. Los diagramas siguen incluyendo sus iconos para que las exportaciones SVG y las fuentes de draw.io puedan abrirse de forma independiente.
