# EmuRV · Criterios de la propuesta

Hecho verificado · confianza alta: el titular pidió explorar isotipos e imagotipos en púrpura y negro, conservar el proyecto en la rama de revisión y elegir el logo antes de reemplazar el actual. EmuRV es un entorno educativo de ensamblador RISC-V; permite avanzar por instrucciones, observar registros y usar una pantalla gráfica. Se consultaron el caso del portafolio y el README del proyecto en lectura. No se copiaron fuentes de la aplicación privada.

Inferencia · confianza moderada: la marca debe resultar clara para estudiantes y docentes, y funcionar también cuando una persona revise el portafolio. Se propone un carácter preciso y accesible, con referencias discretas a las herramientas de programación. Se conserva la escritura EmuRV y la paleta #7A5FD8, #262A20 y #F7F4E6.

Opinión · confianza alta: conviene evitar chips con pines, circuitos decorativos, escudos de certificación y corchetes de código genéricos. El contraste con un modelo de referencia se explica mejor junto a los resultados que como mensaje principal de la marca. La biblioteca de Logo Design se utilizó para estudiar construcción geométrica; no se trazaron sus marcas.

## Alcance de esta ronda

Cuatro conceptos en SVG, con símbolo y nombre; comparación PNG; comparador local con el hero real del portafolio; una ilustración de portada elaborada con Canvas Design y la marca actual. Se revisan tamaño, color, una tinta y fondo oscuro. Las figuras pequeñas son pruebas de concepto, no un paquete definitivo de iconos.
